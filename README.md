Checkout Flow:  
A responsive, multi-step checkout flow built with vanilla HTML, CSS, and JavaScript.

Preview:  
A 4-step checkout form: Contact → Shipping → Payment → Order Confirmation

Features:  
Multi-step form with animated transitions between steps  
Client-side validation on every field with inline error messages  
Credit card number auto-formatting (groups of 4 digits)  
Expiry date auto-formatting and future-date validation   
Payment method toggle — Credit Card or Cash on Delivery  
Responsive layout — adapts from mobile to desktop  
Order confirmation screen populated with the user's submitted data
